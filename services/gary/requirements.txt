# Gary (MusicGen) localhost backend requirements

# Install order for the ROCm preview:
#   1. install AMD ROCm 7.2.1 SDK wheels
#   2. install matching torch/torchaudio/torchvision wheels for Python 3.12
#   3. pip install -e . --no-deps          (audiocraft editable, skip its pinned torch==2.1.0)
#   4. pip install -r requirements.txt     (this file)
#   5. force-reinstall the ROCm Torch wheel set after transitive dependencies
#
# No flash-attn wheel and no xformers shim here: both are CUDA-only, and the
# transformer falls back to PyTorch attention when xformers is absent.
